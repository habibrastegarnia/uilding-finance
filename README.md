# سیستم مدیریت مالی ساختمان — نسخه آنلاین چندکاربره

## نقش‌ها
- **مدیر**: همه امکانات + تأیید واریزی‌های ساکنین + مدیریت رمز واحدها
- **ساکن**: ورود با شماره واحد + رمز → دیدن وضعیت بدهی + اعلام واریزی (در انتظار تأیید)

## ورود پیش‌فرض
| نقش | نام کاربری | رمز |
|-----|-----------|-----|
| مدیر | admin | admin123 |
| ساکن | شماره واحد (مثلاً 101) | همان شماره واحد (101) |

**حتماً بعد از اولین ورود رمز مدیر و واحدها را عوض کنید.**

## اجرای محلی
```bash
pip install -r requirements.txt
python app.py
```
سپس به http://127.0.0.1:5000 بروید.

## استقرار آنلاین (رایگان)
پیشنهاد: PythonAnywhere یا Render
راهنمای کامل استقرار را بعد از تست محلی می‌توانید درخواست کنید.
